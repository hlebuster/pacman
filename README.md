# Pac-Man

Графическая игра на Python 3.14 с тремя заранее заданными уровнями. Игрок
собирает точки и усилители, избегает призраков и переходит на следующий уровень
после очистки карты.

## Состав проекта

```text
pacman/
├── assets/             GIF-изображения игры
├── tests/              автоматические тесты
├── actors.py           игрок, призраки и столкновения со стенами
├── constants.py        настройки игры
├── main.py             запуск и основной игровой цикл
├── mazes.py            карты и их обработка
├── renderer.py         отрисовка и статистика
├── pytest.ini          настройки запуска тестов
└── requirements.txt    сторонние зависимости
```

## Требования

- Python 3.14;
- доступный графический интерфейс операционной системы;
- `pip` для установки `pytest`.

Игра использует только модули стандартной библиотеки Python. `pytest` нужен для
автоматических тестов и указан в `requirements.txt`.

## Установка

Откройте терминал в корневой папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

В Windows при наличии нескольких версий Python можно явно выбрать 3.14:

```powershell
py -3.14 -m pip install -r requirements.txt
```

## Запуск

При стандартном расположении папки `assets` рядом с `main.py`:

```bash
python main.py
```

В Windows с явным выбором Python 3.14:

```powershell
py -3.14 main.py
```

Также игру можно запустить двойным щелчком по `run_game.bat`. Этот способ не
зависит от того, какая версия Python назначена Windows для открытия `.py`.

Можно выбрать любую другую папку с изображениями:

```bash
python main.py --assets-dir "путь/к/папке/assets"
```

Жёстко заданных абсолютных путей в программе нет. Разделители путей формируются
средствами `pathlib`.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` | движение вверх |
| `A` | движение влево |
| `S` | движение вниз |
| `D` | движение вправо |

## Тесты

Из корневой папки проекта выполните:

```bash
python -m pytest
```

Или в Windows:

```powershell
py -3.14 -m pytest
```

Для запуска той же проверки двойным щелчком предусмотрен `run_tests.bat`.

Тесты проверяют тот же код, который используется игрой: обработку карт,
форматирование времени, выбор изображений призраков, проверку ресурсов и сброс
статистики. Для каждой тестируемой функции предусмотрены положительный и
отрицательный сценарии.

## Обозначения карт

| Символ | Объект |
| --- | --- |
| `X` | стена |
| `.` | обычная точка |
| `O` | усилитель |
| `P` | старт игрока |
| `G` | старт призрака |
| пробел | пустая клетка |

После завершения игры выводятся время, итоговый счёт, число собранных точек и
усилителей, а также количество побеждённых призраков.
